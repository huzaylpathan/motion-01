# MOTION/01

A cinematic automotive editorial website built with:

- HTML
- CSS
- Vanilla JavaScript
- Manrope + Space Grotesk
- Scroll reveals
- Counter animations
- Parallax
- Custom cursor
- Interactive technology section
- Responsive layouts

## Run

Open `index.html` with VS Code Live Server.

## Images

The demo uses remote Unsplash image URLs in `style.css`. Replace those URLs with your own automotive photography when you are ready.
